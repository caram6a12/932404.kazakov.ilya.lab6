Описание

Веб-приложение на Node.js с Express. Сервер отдаёт статические страницы и JSON API со списком книг. Книги можно фильтровать по автору и году издания через query-параметры. Реализованы PWA-технологии: манифест, иконки и service worker для кэширования и работы без интернета.

Технологии

Node.js, Express, HTML/CSS/JS, PWA (manifest.json, service-worker.js)

Запуск

npm init -y
npm install express
node server.js

Сервер доступен по адресу http://localhost:3000.

Маршруты

  • GET / — главная страница каталога с формой фильтрации
  • GET /about — информация о проекте
  • GET /api/books — JSON-список всех книг
  • GET /api/books?author=Толстой — фильтр по автору
  • GET /api/books?year=1869 — фильтр по году издания

Без параметров возвращаются все книги. Если по фильтру ничего не найдено — пустой массив [].

Как работает

При открытии главной страница загружает книги через /api/books и отрисовывает их. При вводе автора или года JavaScript отправляет запрос с параметрами, сервер фильтрует массив книг и возвращает JSON. Service Worker кэширует HTML, CSS и JS, поэтому после первого посещения сайт открывается без интернета.

PWA и офлайн

manifest.json описывает приложение и иконки. service-worker.js кэширует статические файлы при первом посещении, после чего страницы открываются без сети.
